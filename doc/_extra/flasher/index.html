ESP-SDR web flasher

Writes an image of the latest esp-sdr-zephyr release onto a board over USB, from Chrome, Edge or Opera on a desktop. How it works · Documentation

This browser has no Web Serial. Use Chrome, Edge or Opera on a desktop, or download an image below and write it with esptool --chip <chip> write-flash 0x0 <file>.

The latest release has no images for this flasher yet: take them from the releases.
